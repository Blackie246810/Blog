# Contributing to the Blog Project

First of all, thank you for your interest in this repository! 

However, please note that this project was created strictly for **personal learning purposes**. The primary goal was to practice using Git, GitHub, and the Render deployment pipeline. 

### 🚫 No Contributions Accepted
Because this is a closed learning experiment that has already served its purpose, **I am not accepting any contributions at this time.** This includes:
* **Pull Requests:** Please do not submit code changes or new features.
* **Bug Fixes:** I am aware there are bugs and malfunctions; however, I am not looking to fix them as this is not a production application.
* **Issue Reports:** There is no need to open issues for any errors you encounter.

### 💡 Feel Free to Fork
If you are also learning and want to see how the code works, you are more than welcome to **Fork** this repository and experiment with it on your own account! 

Thank you for understanding!
