# Security Policy

## ⚠️ "Insecure by Design" Disclaimer
This project is a **learning sandbox** used specifically for testing GitHub workflows and Render deployments. It is **not** a secure application.

Please be aware of the following:
* **No Data Privacy:** There is no authentication system. Any data or "blog posts" you enter are public and can be edited or deleted by any other user.
* **Do Not Use Real Data:** Never enter personal information, real email addresses, or passwords into the live demo.
* **Intentional Vulnerabilities:** The site is intentionally left open and "unprotected" to keep the learning scope focused purely on deployment and basic CRUD logic.

## Reporting a Vulnerability
Because this is a non-serious, dummy project that has already served its educational purpose, **I am not currently patching security vulnerabilities or bugs.** If you find a security flaw, you are welcome to use it as a learning case for your own research, but please do not expect a fix or a response to vulnerability reports.
